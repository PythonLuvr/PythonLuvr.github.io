Privacy policy

LOS Uploader · effective 13 November 2026

LOS Uploader is a private tool used only by its owner to upload videos to the owner's own YouTube channel. This policy explains what it accesses and what happens to it.

What the tool accesses

When the owner signs in with Google, the tool requests two permissions through YouTube API Services:

  • Upload videos (youtube.upload), to publish the owner's own videos.
  • View the channel (youtube.readonly), only to read the signed-in channel's name and confirm uploads go to the right channel.

What is stored, and where

The sign-in token Google issues is stored only on the owner's own computer, so uploads can run without signing in each time. The tool has no server and no database. It does not store, sell, share or transfer any data to anyone.

Other people's data

The tool does not collect or process data about viewers or any other person.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is covered by the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions or through Google security settings. Removing it stops the tool working immediately. Deleting the token file from the owner's computer removes the only stored copy.

Changes

Any change to this policy will be published on this page with a new effective date.
